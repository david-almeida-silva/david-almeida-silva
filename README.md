- ⚙️ **API, Performance & CI/CD:** Validação de contratos, testes de carga e integração de testes automatizados em esteiras de integração contínua.

### 💻 Projetos em Destaque:

*   **[Framework de Automação Web E2E (Playwright)](https://github.com/david-almeida-silva/playwright-ts-e2e-framework)**
    Automação de testes End-to-End aplicando o padrão **Page Object Model (POM)** com Playwright e TypeScript. Inclui execução paralela nativa e validação contínua via GitHub Actions.
*   **[Performance & Load Testing de API (K6)](https://github.com/david-almeida-silva/k6-api-performance-serverest)**
    Suíte de testes de Carga e Estresse para serviços RESTful desenvolvida com **K6**. Implementação de rampas de execução, validação de SLAs/Thresholds e geração dinâmica de massa de dados.
